# PDF Utility Studio

A privacy-focused, browser-only PDF tool. Merge PDFs, convert pages to
JPG/PNG, or turn a PDF into a PowerPoint — all inside the user's browser.
No file is ever uploaded to a server.

## Features

- Merge multiple PDFs into one
- Reorder / remove files before processing
- PDF -> JPG / PNG (downloaded as a ZIP)
- PDF -> PowerPoint (16:9, aspect ratio preserved)
- 100% client-side processing

## Tech Stack

Next.js, TypeScript, React, pdf-lib, PDF.js, PptxGenJS, JSZip

## Run locally

    npm install
    npm run dev

Open http://localhost:3000

## Build

    npm run build
    npm start
